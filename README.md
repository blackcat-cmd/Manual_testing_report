# Manual Testing Report – FieldForceConnect

This repository contains the manual testing artifacts for the FieldForceConnect
application (`https://test.fieldforceconnect.com/`), prepared as part of the
QA Machine Test.

## Modules Covered

1. **Sign Up**
2. **Forgot Password**
3. **Sign in with OTP**
4. **Login**

## Files

| File | Description |
|---|---|
| `FieldForceConnect_Sign_Up.xlsx` | Test cases and field validations for the Sign Up module |
| `FieldForceConnect_Forgot_Password.xlsx` | Test cases and field validations for the Forgot Password module |
| `FieldForceConnect_Sign_in_OTP.xlsx` | Test cases and field validations for the Sign in with OTP module |
| `FieldForceConnect_Login.xlsx` | Test cases and field validations for the Login module |
| `FieldForceConnect_Manual_Testing_Report.docx` | Consolidated summary report including bugs found across all modules |

## Each Excel Sheet Includes

- Test Case ID
- Test Scenario / Description
- Steps to Execute
- Expected Result
- Actual Result
- Status (Pass/Fail)
- Field-level validation checks

## Bugs Found

Any bugs identified during testing are documented in
`FieldForceConnect_Manual_Testing_Report.docx`, along with steps to reproduce
and severity.

## How to Use

1. Open the relevant `.xlsx` file for the module you want to review.
2. Refer to `FieldForceConnect_Manual_Testing_Report.docx` for the summary of
   defects found during testing.# Manual_testing_report
